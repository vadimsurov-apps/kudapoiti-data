## Что здесь лежит
- `places.json` — места для приложения (приложение скачивает его с GitHub). **Генерируется** из `data/kuda-poiti-mesta.xlsx`
  командой `python3 tools/xlsx_to_json.py data/kuda-poiti-mesta.xlsx places.json`. Руками places.json не править.
- `deals.json` — акции/скидки/пробные занятия. Приложение показывает только действующие (`until` ≥ сегодня или пусто).
  Поля: id, place_id (id места из places.json), kind (trial|free|discount|birthday|promo), title, details, code, until, url, checked.
- `icons/<id>.png` + `icons/index.json` + `icons/versions.json` (хэши — приложение перекачивает перерисованные) — иконки новых мест (с 692-го), приложение скачивает их само.
  Исходники SVG — `icons-src/`. Рендер: `python3 tools/render_icons.py <id> ...`.
- `auto/candidates.json` — кандидаты в места из OpenStreetMap (робот, раз в неделю).
- `auto/promo-snippets.json` — фразы про акции с сайтов мест (робот, каждую ночь). `new: true` — новое/изменилось.
- `tools/` — скрипты: `batch_helpers.py` (функция P для строки таблицы), `add_batch14.py` (пример партии),
  `draw_icons.py` (svg, s, eye, face, sparkle, O), `icons_batch14.py` (пример рисования), `MetroStations.swift` (метро).

## Правила для всех
- **Спам казино/букмекеров/даркнета — никогда.** Многие старые сайты мест взломаны и показывают рекламу казино и БК.
  Список таких доменов — `auto/spam-domains.txt`, проверка — `pipeline/spam.py` (`python3 pipeline/spam.py` проверяет
  places.json, deals.json и кэш; `--add` дописывает найденные домены). Нельзя: брать акции/фразы/описания с таких
  сайтов, ставить их адрес в «Сайт» (сборка сама его вырежет), добавлять кандидата только по такому сайту (у кандидата
  тогда поле `spam_site` вместо `url`). Увидел на странице казино/ставки/зеркала/бонусы за депозит — домен в
  `auto/spam-domains.txt`, место подтверждать только по другим источникам (Москомспорт, mos.ru, сайт сети), иначе пропустить.
- Акции — только детско-семейные, с источником-страницей. Не брать: устаревшие («продлена на сентябрь»),
  для пенсионеров/студентов/участников СВО, взрослые бары, спам казино/букмекеров со взломанных сайтов.
- Места — только детские/семейные, работающие. Координаты из OSM ставить с `Точность координат = точно (OpenStreetMap)`.
- Не дублировать места: проверять по названию и расстоянию < 300 м. Не добавлять снова места из `auto/closed.txt`
  (проверены как закрытые или без детской).
- Коммит → `git pull --rebase` → push в main. В конце коротко отчитаться: сколько мест и акций добавлено/снято.

## Сайты: НЕ спрашивать Вадима — WebFetch роботам ЗАПРЕЩЁН
Роботы работают без людей. Любой WebFetch может остановить робота вопросом «Разрешить загрузку страницы?»
и ждать Вадима (так было 07.11 с chessrussian.ru). Поэтому роботы НИКОГДА не вызывают WebFetch. Порядок:
1. Тексты сайтов кандидатов и сетей уже скачаны: `auto/pages/<ключ>.txt`, оглавление `auto/pages/index.json`
   (ключ кандидата = `osm-<type>-<id>`, например osm-node-123). Сначала искать там (Grep по auto/pages).
2. WebSearch можно (он не спрашивает разрешений): сниппеты поиска — тоже источник.
3. Нужна страница, которой нет в кэше, — дописать адреса в `auto/fetch-queue.txt` В НАЧАЛЕ запуска и сразу запушить:
   Action `sites.yml` скачает их за 3–10 минут. Пока ждёшь — делай остальную работу, потом `git pull` и читай auto/pages.
4. Если подтвердить не удалось — место (акцию, исправление) пропустить или оставить на следующий запуск, а не спрашивать.
