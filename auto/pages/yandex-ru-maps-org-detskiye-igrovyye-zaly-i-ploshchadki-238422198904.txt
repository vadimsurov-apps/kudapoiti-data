Самые интересные места города по мнению нашей редакции
Площадки в Академическом парке
4,4 ( 53 )
Сохранить
Рядом с Дарвиновским музеем, в Академическом парке, есть несколько площадок с качелями, лабиринтами, батутами и скалодромом, где дети могут развеяться после экскурсии. Есть отдельная игровая зона с небольшими горками и качелями для малышей.
Площадка в «Музеоне»
4,2 ( 16 )
Сохранить
Совсем рядом со зданием Новой Третьяковки и ЦДХ есть площадка с большими качелями, лазалками, горками и другими аттракционами для детей разных возрастов.
Площадки на ВДНХ
4,4 ( 779 )
Сохранить
На территории ВДНХ есть несколько больших детских площадок, где и малыши, и ребята постарше смогут развеяться после осмотра достопримечательностей. Из самых интересных — «Космос» с моделью лунохода, отсеками космического корабля и макетом Солнечной системы., а также «Фантастический город», где есть качели, лабиринты, башня с горкой-трубой и другие развлечения.
Площадка возле Москва-Сити
4,4 ( 55 )
Сохранить
Стандартная детская площадка с горкой, качелями и лазалками для детей, которая спрятана в небольшом сквере возле московских небоскрёбов. Для взрослых здесь есть лавочки и уличные тренажёры.
Площадка в Нескучном саду
4,6 ( 79 )
Сохранить
После прогулки по Воробьёвым горам взрослые могут отдохнуть, сидя на лавочках, а дети развеселиться на площадке, похожей на строительную площадку, где есть горка, лазалка-подъёмный кран, комплекс в виде экскаватора, песочница и качели.
