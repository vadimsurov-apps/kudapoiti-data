Шары ярости
Участники встают в 2 колонны, поочередно бросают мячики в шары. При попадании шар лопается об иголку, а бирка падает на 1 уровень ниже. Нужно лопнуть все шары, чтобы бирки оказались внизу, а игроки достали их из выдвижной ячейки.
Пирамида ловкости
Задача участников, снять с трубы с пирамидой на основании, не заступая за ограничительную линию, все предметы используя только палку с крюком.
Бешеная сушка
Участники поочередно садятся на велотренажеры. Чем интенсивнее игроки крутят педали — тем больше лампочек загорается. На один «заезд» игроку дается 15 секунд. Необходимо включить весь ряд лампочек, чтобы соответствующее хранилище открылось и выпал ключ.

Сети Старца
Вертикальная сетка, сверху которой закреплены бирки с изображениями по числу игроков +2 запасных. Каждый игрок должен подняться по сетке и снять одну и только одну из бирок.
Карта и куб мудрости
Необходимо найти правильные мешки и добыть бирки за отведенное время. Выбирается случайный флажок страны, соответствующий одной из столиц. Игроки по очереди залезают в куб, ищут нужные мешки.
Адский конвейер
Участники поочередно при помощи гаечных ключей пытаются открыть коробочки, которые едут по действующему конвейеру. К каждой из них подходит только один ключ. Задача участников собрать как можно больше ключей.
Куб с тараканами
Игрокам необходимо найти записки-подсказки, которые прикреплены к брюшкам тараканов. Победившая команда сохраняет полный состав. Проигравшая команда теряет одного из участников — он отправляется в клетку к Старцу Фура.
Кольцеброс
На полу установлен шест, на который игроки по очереди кидают кольца. Задача участников накинуть больше колец, чем команда соперника. Победившая команда получает ключ.
Спасение узника
Игроки по очереди пытаются достать подходящий ключ, который находится в кубе заполненный тараканами или червями-зоофобосами, чтобы открыть клетку и спасти узника.
Стаканы
Участники становятся за столом напротив друг друга и ждут, когда загорится один из стаканов. Задача игроков первым схватить загоревшийся стакан.
Буквенное поле
До заветной сокровищницы остаётся один шаг, найти общее для всех подсказок слово и распределиться командой по буквам в алфавите и путь к сокровищнице будет открыт
Сбор золота
По сигналу ведущего золото из сундука рассыпается по клетке. Игроки победившей команды по итогу подсчета ключе, пытаются собрать как можно больше монет, до финального сигнала.
