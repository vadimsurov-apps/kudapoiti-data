Музейное объединение Одинцовского городского округа предоставляет льготы на посещение выставок и экспозиций только при предъявлении удостоверения или иного документа, дающего право на получение льгот.
Льготный билет приобретается на основании сведений из государственной информационной системы "Единая централизованная цифровая платформа в социальной сфере", либо при предъявлении документа.
ЛЬГОТНЫЕ БИЛЕТЫ:
- ПЕНСИОНЕРЫ
Документ для предъявления: пенсионное удостоверение РФ
- ДЕТИ ОТ 6 ДО 17 ЛЕТ ВКЛЮЧИТЕЛЬНО
Документ для предъявления: свидетельство о рождении или паспорт
- СТУДЕНТЫ СРЕДНИХ ПРОФЕССИОНАЛЬНЫЙ И ВЫСШИХ УЧЕБНЫХ ЗАВЕДЕНИЙ ОЧНОЙ ФОРМЫ ОБУЧЕНИЯ
Документ для предъявления: студенческий билет
БЕСПЛАТНОЕ ПОСЕЩЕНИЕ БЕЗ ЭКСКУРСИОННОГО ОБСЛУЖИВАНИЯ:
- ГЕРОИ СОВЕТСКОГО СОЮЗА, ГЕРОИ РОССИЙСКОЙ ФЕДЕРАЦИИ, ПОЛНЫЕ КАВАЛЕРЫ ОРДЕНА СЛАВЫ
Документ для предъявления: удостоверение или грамота о присвоении соответствующего звания
- ВЕТЕРАНЫ И ИНВАЛИДЫ ВОВ, БЫВШИЕ НЕСОВЕРШЕННОЛЕТНИЕ УЗНИКИ, НЕЗАКОННО РЕПРЕССИРОВАННЫЕ, УЧАСТНИКИ ЛИКВИДАЦИИ ЧАЭС
Документ для предъявления: удостоверение соответствующей категории
- ДЕТИ-СИРОТЫ И ДЕТИ, ОСТАВШИЕСЯ БЕЗ ПОПЕЧЕНИЯ РОДИТЕЛЕЙ
Документ для предъявления: удостоверение соответствующей категории
- ВОЕННОСЛУЖАЮЩИЕ СРОЧНОЙ СЛУЖБЫ
Документ для предъявления: военный билет с записью, подтверждающей прохождение военной службы
- СОТРУДНИКИ ГОСУДАРСТВЕННЫХ И НЕГОСУДАРСТВЕННЫХ МУЗЕЕВ
Документ для предъявления: удостоверение сотрудника музея
- ИНВАЛИДЫ I И II ГРУППЫ С ОДНИМ СОПРОВОЖДАЮЩИМ ЛИЦОМ
Документ для предъявления: справка об установлении инвалидности
- ВЕТЕРАНЫ БОЕВЫХ ДЕЙСТВИЙ
Документ для предъявления: удостоверение "Ветеран боевых действий"
- ДЕТИ-ИНВАЛИДЫ С ОДНИМ СОПРОВОЖДАЮЩИМ ЛИЦОМ
Документ для предъявления: справка об установлении инвалидности
- ДЕТИ ДО 5 ЛЕТ ВКЛЮЧИТЕЛЬНО
Документ для предъявления: свидетельство о рождении
- ЧЛЕНЫ МНОГОДЕТНЫХ СЕМЕЙ
Документ/основание для предъявления: сервис "Цифровой ID" либо удостоверение члены многодетной семьи (в т.ч. в электронном виде)
- УЧАСТНИКИ СВО И ЧЛЕНЫ ИХ СЕМЕЙ
Документ/основание для предъявления: сервис "Цифровой ID" либо военный билет, справка из военкомата
- ЧЛЕНЫ МЕЖДУНАРОДНОГО СОВЕТА МУЗЕЕВ ИКОМ (ICOM)
Документ для предъявления: членская карта ИКОМ (ICOM)
БЕСПЛАТНОЕ ПОСЕЩЕНИЕ В ПОСЛЕДНЕЕ ВОСКРЕСЕНЬЕ МЕСЯЦА БЕЗ ЭКСКУРСИОННОГО ОБСЛУЖИВАНИЯ:
- ПЕНСИОНЕРЫ
Документ для предъявления: пенсионное удостоверение РФ
- СТУДЕНТЫ СРЕДНИХ ПРОФЕССИОНАЛЬНЫЙ И ВЫСШИХ УЧЕБНЫХ ЗАВЕДЕНИЙ ОЧНОЙ ФОРМЫ ОБУЧЕНИЯ
Документ для предъявления: студенческий билет
- УЧИТЕЛЯ
Документы для предъявления: справка с места работы и документ, удостоверяющий личность
АКЦИЯ ДЛЯ УЧАСТНИКОВ СВО И ЧЛЕНОВ ИХ СЕМЕЙ:
В последнее воскресенье каждого месяца музей проводит бесплатные экскурсии для участников СВО и членов их семей. Для групп более 5 человек обязательна предварительная запись.
Документ/основание для предъявления: сервис "Цифровой ID" либо военный билет, справка из военкомата
Приказ о бесплатном и льготном посещении МБУК "Музейное объединение Одинцовского городского округа" для лиц, имеющих основания
Инструкция по использованию сервиса "Цифровой ID"

Независимая оценка качества условий оказания услуг организациями культуры
Данный раздел создан в соответствии со статьями 36.1 и 36.2 Основ законодательства Российской Федерации о культуре с целью размещения актуальной информации о проведении независимой оценки качества условий оказания услуг организациями в сфере культуры (далее – независимая оценка), а также для обеспечения технической возможности выражения мнений получателями услуги о качестве условий оказания услуг организациями культуры
Информация о независимой оценке размещается на Официальном сайте для размещения информации о государственных (муниципальных) учреждениях – bus.gov.ru .
