## Робот «навигатор» (сверщик) — как попасть внутрь, телефон и сайт (каждый час, :25 UTC; замок auto/lock-navigator)
Вадим 07.11: «максимально точные подробности, как попасть: подъезд, этаж, номер помещения, домофон, шлагбаум,
платная или бесплатная парковка». Пишется в колонку «Как найти» (приложение и сайт показывают её целиком, с переносами)
и «Парковка» (да/нет).
Сырьё (собирается само):
- auto/access-snippets.json — фразы со страниц «Контакты / Как добраться» сайтов мест (promos.yml, каждые 3 часа);
- auto/osm-access.json — из OSM: этаж/помещение объекта, входы здания с номерами подъездов, шлагбаумы и ворота ≤60 м,
  парковки ≤300 м (fee=yes платная / no бесплатная, тип, вместимость) (osm-local.yml, после новых мест и каждую ночь);
- auto/pages/<ключ>.txt — тексты сайтов; WebSearch (2ГИС/Яндекс в сниппетах часто пишут «вход со двора», «3 этаж»).
Формат «Как найти» — короткие строки через перевод строки, только то, что известно, порядок:
`Вход: …` (с какой стороны, подъезд №, вывеска, арка, через ТЦ — какой вход) / `Этаж: …, помещение/офис № …` /
`Домофон: …` / `Шлагбаум: …` (есть, как проехать — «сказать охране…») / `Парковка: …` (бесплатная/платная, где, сколько мест;
городская платная — так и писать) / `Ориентир: …` (если помогает). Пример:
«Вход: со двора, подъезд 3, вывеска «Карапуз»\nЭтаж: 2, офис 204\nДомофон: 204\nПарковка: бесплатная во дворе, мест мало»
Правила:
- Только подтверждённое источником (сайт места, OSM, сниппет поиска с адресом этого филиала). Не придумывать, не обобщать
  с соседнего филиала сети. У сетей фразы с сайта относить к филиалу по адресу.
- Парковка из OSM: fee=yes — «платная», fee=no — «бесплатная», без fee — писать только «парковка рядом (~N м)», без «платная/бесплатная».
  «Парковка» = да, если есть парковка ≤150 м или сайт пишет о ней; нет — только если сайт прямо пишет, что парковки нет.
- Старое содержимое «Как найти» не терять: полезное перенести в новый формат.
- Ничего не нашли — тоже записать (как «просмотрено»), чтобы не брать снова 30 дней.
Порядок за запуск (до 80 мест): места без «Как найти» с точной точкой → остальные без «Как найти» → у кого «Как найти»
старше 90 дней (auto/access-reviewed.json). Сначала популярные типы: кафе, детские центры, секции (часто во дворах и ТЦ).
Запись: собрать {id: {"how": "...", "parking": "да"|"нет"|null, "src": "сайт|OSM|поиск"}} в файл и
`python3 tools/set_access.py файл.json` — сам найдёт таблицу места, пропустит таблицы роботов с замком.
Коммит: таблицы, auto/access-reviewed.json; замок удалить тем же коммитом; git pull --rebase; push.
В конце одна строка: сколько мест заполнено (вход/этаж/домофон/шлагбаум/парковка), сколько без данных.
**Телефон и сайт (Вадим 09.11: «во всех карточках — рабочие телефоны и ссылки на основной сайт»).** Тем же проходом:
- Телефон — рабочий номер ЭТОГО места/филиала (не общий колл-центр сети, если у филиала есть свой; если есть только
  общий — его). Источники: ссылки tel: с сайта места (auto/access-snippets.json → `phones`), страница «Контакты»
  (auto/pages), сниппеты 2ГИС/Яндекса с адресом филиала (WebSearch). Объект OSM с тем же названием сборка подставляет
  сама (auto/osm-access.json → poi.phone), его не дублировать — но если он неверный, записать правильный.
- Сайт — официальный сайт места или страница филиала на сайте сети. НЕ агрегаторы (2ГИС, Яндекс, Zoon, Афиша,
  restoclub и т.п.), не соцсети, если есть сайт (если сайта нет — официальная страница VK/Telegram допустима),
  не домены из auto/spam-domains.txt. Если в таблице «Сайт» агрегатор/чужой/мёртвый — дать правильный с url_override.
- Запись — в тот же файл для set_access.py: "phone": "+7 …" / "url": "https://…" / "url_override": true;
  искал и не нашёл — "phone": null (запомнится, повтор через 60 дней). Пишется в auto/contacts.json, применяет сборка.
- Порядок: сначала места без телефона в places.json и без записи в auto/contacts.json (кафе, детские центры, секции,
  бассейны), до 100 мест за запуск (вход/парковка — для тех же мест, если ещё не заполнено).
- Коммитить также auto/contacts.json.
