## Независимый проверяющий — ChatGPT (Вадим 10.11)
- Очередь для него — gpt/queue.json (tools/gpt_queue.py, обновляет сборка), инструкция и формат отчёта — gpt/README.md.
  Его отчёты — gpt/reports/*.json; сборка разбирает их tools/gpt_import.py → auto/gpt-checks.json (совпадения) и
  auto/gpt-disputes.json (расхождения, закрыто/переехало).
- **Вадим 10.11: находка GPT со ссылкой-источником — достаточное подтверждение, менять сразу, людей не ждать.**
  Это делает автоматически Action gpt.yml (tools/gpt_import.py → tools/gpt_apply.py → сборка → push): wrong со ссылкой
  исправляет, ok со ссылкой засчитывает как переподтверждение, closed со ссылкой — снимает с карты. Роботам вручную это
  не повторять. Отчёты кладёт задача по расписанию в ChatGPT (облако, gpt/CHATGPT-TASK.md; Вадим 10.11: постоянно
  включённого компьютера нет): файл в gpt/reports/, PR (gpt-pr.yml вливает сам) или issue «Отчёт ChatGPT …» от
  vadimsurov-apps (gpt-intake.yml достаёт JSON). Вадим ничего не пересылает. Если он всё же прислал JSON в чат —
  сохранить в gpt/reports/ и запушить, остальное сделает gpt.yml.
- **Codex по подписке Вадима (11.11, «бесплатный и не менее продуктивный вариант»)**: gpt-codex.yml каждые 20 минут держит в работе
  CODEX_SLICES пачек по CODEX_N мест (переменные репозитория; по умолчанию 12 × 25; с 13.11 новая пачка выдаётся сразу после сдачи предыдущей (workflow_run после приёма отчёта) — Вадим 13.11: «можно его ускорить?»; расход недельного лимита Codex на тарифе Pro 100 ≈ 1% на 330 мест, следить по его скриншотам; Вадим 12.11: «надо брать больше мест, чтобы быстрее перепроверить все… меньше 3 по 25 в час нежелательно»): PR `codex/check-<имя>` с gpt/slices/<имя>.json
  + комментарий «@codex …» от Вадима (секрет CODEX_PAT). Codex читает AGENTS.md → gpt/RULES.md (свод этих правил, собирает
  tools/gpt_rules.py) и отдаёт полный JSON отчёта в итоговом сообщении-комментарии PR (12.11: в ветку его коммит не попадает) → gpt-codex-intake.yml сохраняет gpt/reports/<имя>.json и закрывает PR → gpt.yml применяет. Среда Codex — «прежнего типа» (chatgpt.com/codex/cloud/settings/environments), новые облачные среды вызовы из GitHub не обслуживают. Новые правила
  в CLAUDE.md попадают к GPT сами. Настройка — gpt/CODEX-SETUP.md.
- **Сверщик каждый запуск сначала берёт открытые споры** (resolved: false, до 15) — это только то, что автоматика не
  смогла применить (часы в непонятном формате, точка дальше 500 м, «как найти» не в нашем формате, нет детской
  комнаты у кафе, переезд без адреса, таблица под замком): разобрать по источнику из спора и своим, исправить через
  set_verified.py (src: источник + «нашёл GPT»), записать "resolved": true, "result": "…".
