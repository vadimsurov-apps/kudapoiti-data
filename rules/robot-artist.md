## Робот «художник» (каждые 3 часа, :55 UTC; замок auto/lock-artist)
1. `python3 tools/check_unique.py` → auto/icon-repeats.json — иконки с повторами. Взять до 40 штук (сначала те, что
   повторяются чаще; встроенные в приложение тоже можно — приложение берёт перерисованную с GitHub).
2. Для каждой придумать НОВУЮ уникальную идею по теме места (название, вид занятия, район) и нарисовать отдельный SVG
   вручную (tools/draw_icons.py: svg, s, eye, face, sparkle). Строка реестра — формат «герой: … | сцена: …».
3. Отрендерить, `python3 tools/check_unique.py <id…>` → 0 повторов, посмотреть на 40 px (понятно ли, что это за место).
4. Коммитить только icons-src/<id>.svg, icons-src/subjects.txt и свой скрипт в tools/; замок удалить тем же коммитом;
   git pull --rebase; push. В конце одна строка: сколько перерисовано, сколько повторов осталось.
