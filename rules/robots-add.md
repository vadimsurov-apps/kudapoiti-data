**Вадим 08.11: мест ещё сотни — «кандидаты кончились» не повод останавливаться.** Пример: в его ЖК два кафе с детскими
игровыми, которых нет на карте; детский бассейн в ЖК «Фили Град» тоже не было. Каталоги и auto/candidates.json — только
начало. Основной способ теперь — **систематический поиск по районам**:
- Районы — auto/search-areas.json (`metro` — 265 станций Москвы, `towns` — города Подмосковья). Прогресс — у каждого
  робота свой файл auto/search-progress-<робот>.json `{район: "YYYY-MM-DD"}` (коммитить вместе с таблицей). Каждый запуск: взять 12–15 районов, где робот не искал
  дольше всего (нет в прогрессе — первыми), по каждому 2–3 запроса WebSearch своей темы, например:
  cafes — «кафе с детской комнатой у метро <район>», «ресторан с детской игровой <район>», «семейное кафе с аниматором <район>»;
  sections — «детская секция <вид спорта> <район>» (самбо, дзюдо, бокс, карате, гимнастика…);
  pools — «детский бассейн <район>», «обучение плаванию детей с 3 лет <район>», «грудничковое плавание <район>», «школа плавания для детей <район>», «ЖК <название> бассейн для детей»;
  creative — «танцы для детей <район>», «балетная школа <район>», «вокал для детей <район>», «музыкальная школа <район>»,
  «театральная студия для детей <район>», «рисование для детей <район>», «гончарная мастерская для детей <район>»;
  rare — «падел <район>», «хоккей / фигурное катание для детей <район>», «волейбол для детей <район>», «картинг / скалодром / верёвочный парк / батутный центр <район>»;
  fun — «детский центр / квест / мастер-класс для детей <район>»;
  edu — «монтессори <район>», «центр раннего развития <район>», «подготовка к школе <район>», «английский для детей <район>», «робототехника для детей <район>»,
  «программирование для детей <район>», «лего-конструирование <район>», «частный детский сад <район>», «скорочтение для детей <район>»,
  «математический кружок <район>», «ментальная арифметика <район>».
  После поиска записать дату в прогресс (даже если ничего нового).
- Новые ЖК: в инфраструктуре жилых комплексов (кафе с игровой, бассейны, студии, секции) много мест, которых нет в
  каталогах: запросы «ЖК <название> кафе детская комната», «ЖК <название> бассейн для детей» по крупным ЖК района.
- Списки филиалов сетей на сайтах сетей (через fetch-queue → auto/pages), страницы-подборки 2ГИС/Zoon/Яндекса по
  району из сниппетов поиска.
- Каждое найденное место подтверждать (сайт места/сети, сниппет с адресом), проверять дубли — как обычно.

Правила для каждого робота:
0. **Свой замок** `auto/lock-<робот>` (время UTC ISO). Если моложе 75 минут — предыдущий запуск ещё идёт: выйти.
   Иначе записать, закоммитить и запушить сразу. В конце удалить тем же коммитом, что и данные.
1. Писать новые строки ТОЛЬКО в свою таблицу `data/parts/<робот>.xlsx`: запускать скрипты с `KP_PART=<робот>`
   (batch_helpers.SRC тогда указывает на неё). Основную таблицу и чужие таблицы не трогать.
2. Коммитить ТОЛЬКО свою таблицу, `icons-src/<id>.svg` своих мест, `icons-src/subjects.txt` и свой auto/search-progress-<робот>.json. places.json, icons/*.png,
   index.json, страницы p/ и каталог собирает GitHub Action `build.yml` сам после пуша — их не коммитить
   (локально собрать можно: `python3 tools/build_all.py` — для проверки).
3. Дубли: перед добавлением проверить places.json и ВСЕ data/parts/*.xlsx (название + < 300 м).
4. Иконки: прочитать все листы icons-catalog и `icons-src/subjects.txt`. Каждую иконку придумать и нарисовать отдельно
   (правило АБСОЛЮТНОЙ уникальности), реестр — `id — герой: … | сцена: …`. Перед коммитом: render_icons.py <свои id> →
   check_unique.py <свои id> → код 0, иначе перерисовать. Генераторы «герой × сцена» не использовать.
   Если при `git pull --rebase` в subjects.txt оказался такой же сюжет у другого робота — свой перерисовать.
5. Цель — 100 мест за запуск, качество важнее количества (работающие, детские, с адресом; детская комната у кафе —
   подтверждённая). Меньше 100 качественных — так и написать. В конце одна строка: сколько добавлено по категориям.
6. Пуш: `git pull --rebase` → push; при конфликте в своей таблице такого быть не может (она только твоя), в subjects.txt —
   объединить обе версии строк.
