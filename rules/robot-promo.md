## Робот акций (каждые 3 часа; сбор фраз с сайтов — Action promos.yml тоже каждые 3 часа, за ~40 мин до робота)
Акции — главный крючок для новых пользователей: их должно быть много, свежих и проверенных.
0. Замок `auto/lock-daily`. Новые места робот акций пишет только в основную таблицу (чужие data/parts не трогает).
1. Снять просроченные акции из deals.json; для акций с checked старше 30 дней — перепроверить страницу (через auto/pages и очередь fetch-queue, НЕ WebFetch) и обновить checked
   (не больше 15 за запуск, самые старые первыми).
2. ОЧЕРЕДЬ: `auto/promo-snippets.json` → sites. Разбирать сайты, у которых есть snippets и `auto/promo-reviewed.json[ref] != hash`
   (флаг new НЕ использовать — он сбрасывается при каждом сборе). По каждому:
   - реальная детско-семейная акция с источником → в deals.json (место есть в places.json — к нему; нет — добавить место
     в основную таблицу + иконку по правилам + акцию);
   - после разбора (акция добавлена или нет) записать `promo-reviewed.json[ref] = hash`.
   За запуск — до 60 сайтов, сначала те, у кого new: true, затем остальные.
3. ПОИСК: каждый запуск 5–8 запросов WebSearch по одной теме по кругу (номер запуска = час UTC // 3 % 8):
   0 батуты и игровые центры, 1 кафе с детской комнатой и детское меню, 2 бассейны и секции (пробное бесплатно),
   3 танцы и творчество, 4 музеи и театры (бесплатные дни, семейные билеты), 5 квесты, картинг, скалодромы,
   6 дни рождения детей (скидка имениннику), 7 сети: Joki Joya, KidZania, Мастерславль, Чайхона №1, Андерсон, «Чудо-остров».
   Брать только то, что подтверждено страницей места/сети (кэш auto/pages; нужной страницы нет — в fetch-queue и прочитать после скачивания) и действует сейчас.
4. Цель — 20+ новых акций за запуск. Коммит: deals.json, auto/promo-reviewed.json, основная таблица, свои svg и subjects.txt;
   замок удалить тем же коммитом, git pull --rebase, push. В конце одна строка: акций добавлено/снято/перепроверено, сайтов в очереди осталось.
