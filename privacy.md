# Политика конфиденциальности приложения «Куда пойти»

Действует с 3 ноября 2026 года.

«Куда пойти» — карта мест для прогулок с детьми в Москве и Подмосковье. Приложение сделано так, чтобы о вас ничего не собирать.

## Что мы не собираем

- Нет регистрации и аккаунтов.
- Нет рекламы, аналитики и трекеров.
- Мы не получаем и не храним ваши данные на своих серверах — своих серверов у приложения нет.

## Что хранится только на вашем телефоне

- Ответы при первом запуске (возраст детей, интересы, бюджет), избранные места и история посещений.
- Эти данные не покидают устройство и удаляются вместе с приложением.

## Геопозиция

- Если вы разрешите доступ к геопозиции, приложение использует её, чтобы посчитать, сколько ехать до мест. Можно вместо этого указать станцию метро.
- Геопозиция не сохраняется и никуда не отправляется, кроме запросов, описанных ниже.

## Сторонние сервисы

- **Погода.** Чтобы показать погоду, приложение отправляет сервису Open-Meteo (open-meteo.com) приблизительные координаты. Сервис не получает никаких данных о вас.
- **Apple Карты.** Для уточнения точек на карте приложение отправляет в Apple Карты названия и адреса мест (не ваши данные). Карта и маршруты работают на сервисах Apple по их правилам.
- **Список мест.** Приложение скачивает обновлённый список мест с GitHub (github.com). При этом передаётся только сам запрос файла.
- **Сообщить об ошибке.** Кнопка «Здесь ошибка» открывает Telegram с готовым текстом о месте. Сообщение отправляется, только если вы сами нажмёте «Отправить», и обрабатывается по правилам Telegram.

## Дети

Приложение предназначено для родителей. Мы не собираем данные детей.
