# Ежедневная выгрузка для пакета передачи проекта

Эту папку каждый день (20:47 МСК) обновляет робот бэкапа:
- `robots.md` — полные тексты всех роботов (запланированных задач ИИ): название, расписание, текст целиком;
- `status.md` — текущие цифры: места, категории, точность точек, «как найти», акции, сообщения бота, повторы иконок.

Основной пакет передачи (инструкция восстановления, история требований, спецификация, код приложения) — в закрытом
репозитории `vadimsurov-apps/KudaPoiti`, папка `handover/`. Правила проекта — `CLAUDE.md` в корне этого репозитория.
