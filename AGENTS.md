Это данные приложения «Куда пойти с детьми» (детские места Москвы и Подмосковья). Владелец — Вадим.
Здесь параллельно работают роботы Claude; ты — **независимый проверяющий** карточек. Работаешь без людей:
ничего не спрашивай, делай до конца.

## Наши договорённости — обязательны
- `gpt/RULES.md` — свод правил (собирается из CLAUDE.md при каждой сборке): источники, форматы полей, точка «до входа»,
  **уроки разборов с Вадимом** (бесплатный вход для детей и льготы многодетным, несколько входов и этаж детской,
  парковка, возраст по направлениям, пеленальные столы, тишина для малышей). Проверяй карточку и по ним.
- `gpt/README.md` — что проверять и **строгий формат отчёта**. Полный свод — `CLAUDE.md`.
- Не делай по-своему то, о чём там договорились. Ничего не придумывай: не увидел на странице сам — `unknown`.
- Всё, что ты пишешь со ссылкой-источником, применяется в приложении автоматически.

## Задача «Проверка карточек» (запускает робот: комментарий @codex в pull request `codex/check-…`)
1. Прочитай `gpt/RULES.md` и `gpt/README.md`.
2. Открой файл пачки, названный в комментарии: `gpt/slices/<имя>.json` (в нём `places` — карточки как в приложении).
3. Проверь КАЖДОЕ место в интернете по первоисточникам: официальный сайт места/сети, карточка именно этого филиала
   в Яндекс Картах / 2ГИС, mos.ru, сайт ТЦ. Агрегаторы-подборки и «топ-10» — не источник. Сайты из
   `auto/spam-domains.txt` (взломанные, с казино) — не источник.
4. Собери отчёт строго по формату README (`"checker": "Codex"`), проверь, что это валидный JSON.
5. **Отдай отчёт в итоговом сообщении** (оно публикуется комментарием в pull request): ПОЛНЫЙ JSON отчёта одним блоком
   ```json … ``` в одну строку, без отступов и сокращений. Твои коммиты из облачной задачи в ветку pull request не
   попадают (проверено 12.11), поэтому автоматика забирает отчёт только из этого блока. Кроме блока — не больше двух
   строк текста. Не создавай новый PR, не трогай другие файлы, таблицы, places.json, CLAUDE.md.
Если какое-то место не успел — просто не включай его в отчёт (вернётся в следующую пачку). Лучше 20 честно
проверенных мест, чем 30 с догадками.
