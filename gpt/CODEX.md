# ChatGPT (Codex) — проверка карточек по расписанию, без пересылки файлов

Как это работает: Codex сам берёт очередь `gpt/queue.json` из этого репозитория, проверяет места в интернете и
коммитит отчёт в `gpt/reports/`. GitHub Action `gpt.yml` сразу применяет найденное (со ссылкой-источником) к карте.
Вадим ничего не пересылает.

## Настройка один раз (Вадим, ~10 минут)
1. Установить приложение **Codex** (ChatGPT → Codex, вход той же подпиской) на компьютер, который обычно включён.
2. В Codex: открыть проект → «клонировать репозиторий» `vadimsurov-apps/kudapoiti-data` (вход в GitHub, доступ на запись).
3. В настройках проекта/песочницы разрешить **доступ в интернет** (иначе Codex не сможет открывать сайты мест и
   Яндекс Карты) и `git push`.
4. Слева **Scheduled → New task** → «Standalone», проект kudapoiti-data, режим «local project» (не worktree),
   расписание — каждые 3 часа (или чаще, если хватает лимитов). В текст задачи вставить блок ниже целиком.
5. Нажать «Run now» один раз и посмотреть, что отчёт появился в `gpt/reports/` на GitHub. Дальше — само.

Компьютер должен быть включён и Codex запущен: так устроены задачи по расписанию в приложении Codex.

## Текст задачи для Codex (копировать целиком)
```
Ты — независимый проверяющий карточек приложения «Куда пойти с детьми». Работаешь без людей, ничего не спрашивай.
1. git pull --rebase origin main.
2. Прочитай gpt/README.md — там что проверять и строгий формат отчёта. Всё, что ты пишешь со ссылкой-источником,
   применяется в приложении автоматически, поэтому ставь ok/wrong только по тому, что сам увидел на странице.
3. Возьми из gpt/queue.json первые 25 мест, id которых нет ни в одном файле gpt/reports/*.json.
4. Проверь каждое по первоисточникам в интернете: официальный сайт места/сети, карточка Яндекс Карт / 2ГИС именно
   этого филиала (адрес, «Больше не работает», вход, часы, телефон, средний чек), mos.ru. Не агрегаторы-подборки.
5. Запиши отчёт в gpt/reports/<ГГГГ-ММ-ДД>-<ЧЧММ>.json строго по формату README, проверь, что это валидный JSON
   (python3 -m json.tool файл).
6. git add только этот файл; git commit -m "Отчёт ChatGPT <дата>: N мест"; git pull --rebase origin main; git push origin main.
   Если push не прошёл — повтори pull --rebase и push (до 5 раз).
7. Ответь одной строкой: сколько мест проверено, сколько расхождений, сколько закрытых.
```

## Если Codex недоступен
Запасной путь — тот же текст задачи в обычном чате ChatGPT; отчёт (JSON) переслать роботу. Это ручной режим.
