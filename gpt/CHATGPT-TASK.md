# ChatGPT: проверка карточек по расписанию в облаке (без компьютера)

Задача по расписанию на сайте ChatGPT работает в облаке. Она берёт очередь мест, проверяет их в интернете и кладёт
отчёт в GitHub. Дальше всё само: отчёт принимается (gpt-intake.yml / gpt-pr.yml / gpt.yml) и применяется к карте.

## Настройка один раз (Вадим, ~10 минут)
1. chatgpt.com → Настройки → Приложения/Коннекторы → **GitHub** → подключить, дать доступ к репозиторию
   `vadimsurov-apps/kudapoiti-data` (с правом записи, если спросит).
2. Новый чат → вставить текст задачи ниже → в конце дописать: «Запускай это каждые 3 часа». ChatGPT создаст задачу
   по расписанию (или: значок часов / раздел «Задачи» → новая задача, тот же текст, каждые 3 часа).
3. Первый раз запустить вручную и посмотреть, что получилось:
   - появился файл в `gpt/reports/`, или pull request, или issue «Отчёт ChatGPT …» — всё в порядке, дальше само;
   - ChatGPT написал, что не может записать в GitHub, — сообщить роботу, он подберёт другой способ.

## Текст задачи (копировать целиком)
```
Ты — независимый проверяющий карточек приложения «Куда пойти с детьми» (детские места Москвы и Подмосковья).
Работаешь по расписанию без людей — ничего не спрашивай, делай до конца.

1. Открой инструкцию https://raw.githubusercontent.com/vadimsurov-apps/kudapoiti-data/main/gpt/README.md и строго
   следуй её формату.
2. Открой очередь https://raw.githubusercontent.com/vadimsurov-apps/kudapoiti-data/main/gpt/queue.json и возьми
   первые 25 мест (очередь сама обновляется после каждого отчёта).
3. Каждое место проверь в интернете по первоисточникам: официальный сайт места/сети, карточка именно этого филиала
   в Яндекс Картах или 2ГИС («Больше не работает», адрес, вход, часы, телефон, средний чек, детская комната).
   Всё, что ты пишешь со ссылкой, применяется в приложении автоматически — ставь ok/wrong только по тому,
   что сам увидел на странице, иначе unknown. Закрытие — только со ссылкой, где это прямо сказано.
4. Сохрани отчёт (один JSON строго по формату README) в GitHub-репозиторий vadimsurov-apps/kudapoiti-data
   через подключение GitHub — первым способом, который получится:
   а) файл gpt/reports/<ГГГГ-ММ-ДД>-<ЧЧММ>.json прямо в ветку main;
   б) иначе — pull request с этим единственным файлом;
   в) иначе — issue с заголовком «Отчёт ChatGPT <дата> <время>», в тексте — весь JSON в блоке ```json … ```.
5. Ответь одной строкой: сколько мест проверено, сколько расхождений, сколько закрытых, каким способом сохранён отчёт.
```
