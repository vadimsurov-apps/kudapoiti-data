# Независимая проверка карточек (для ChatGPT или любого другого ИИ)

Ты — независимый проверяющий данных приложения «Куда пойти с детьми» (карта детских мест Москвы и Подмосковья).
Другие роботы уже собрали карточки. Твоя задача — **проверить их заново по первоисточникам, не доверяя нашим данным**,
и вернуть отчёт строго в формате ниже. Ничего не придумывай: если не нашёл подтверждения — так и пиши.

## Сначала — наши договорённости (обязательно)
`https://raw.githubusercontent.com/vadimsurov-apps/kudapoiti-data/main/gpt/RULES.md` — свод правил, по которым работают
и наши роботы: что считается источником, форматы полей, правила точек «до входа», и **уроки разборов с владельцем** (например:
у мест с билетами — до какого возраста дети бесплатно и льготы многодетным; несколько входов и этаж детской; как заехать на
парковку; возраст по каждому направлению). Проверяй карточку и по ним тоже: если по уроку должно быть заполнено поле, а оно
пустое и ты нашёл источник — укажи значение как `wrong` со ссылкой. Не делай по-своему то, о чём там договорились.

## Откуда брать работу
`https://raw.githubusercontent.com/vadimsurov-apps/kudapoiti-data/main/gpt/queue.json` — список мест (до 800),
сначала самые важные и давно не проверенные. За один раз бери **первые 25 мест, которых ещё нет в твоих отчётах**.

## Что проверить у каждого места
1. **Работает ли сейчас** (не закрыто, не переехало).
2. **Адрес** — точный, с корпусом/строением; для ТЦ — название ТЦ и этаж.
3. **Точка** — `lat`, `lon` должны стоять на входе в это заведение (или на объекте: парк, музей). Сравни с Яндекс Картами
   / 2ГИС: укажи координаты места по карте и примерное расстояние до нашей точки в метрах.
4. **Как найти** — вход (с какой стороны, подъезд, вывеска), этаж, домофон, шлагбаум, парковка (платная/бесплатная).
5. **Часы работы** (и часы детской комнаты, если отличаются).
6. **Цена**: детский/взрослый билет; у кафе и ресторанов — средний чек (`price_adult`).
7. **Телефон** именно этого филиала и **официальный сайт** (не агрегатор).
8. **Возраст** (`age_min`–`age_max`) — с какого возраста реально берут/интересно.
9. Для кафе/ресторанов: **есть ли детская комната/игровая** (и часы её работы).

Источники (сильные → слабые): официальный сайт места/сети → карточка Яндекс Карт / 2ГИС именно этого филиала →
mos.ru / сайт ТЦ → свежие отзывы. Агрегаторы-подборки и статьи «топ-10» — не источник.

## Формат отчёта (строго JSON, один файл на пачку)
Файл `gpt/reports/YYYY-MM-DD-N.json`:
```json
{
  "checker": "ChatGPT",
  "date": "2026-11-10",
  "places": [
    {
      "id": "cafe-osteria-kievskaya",
      "status": "works",                       // works | closed | moved | not_found
      "fields": {
        "address":  {"verdict": "ok",    "value": "пл. Киевского вокзала, 2, ТЦ «Европейский», 3 этаж", "source": "https://..."},
        "point":    {"verdict": "wrong", "value": [55.74471, 37.56659], "distance_m": 40, "source": "https://yandex.ru/maps/org/..."},
        "hours":    {"verdict": "ok",    "value": "пн–чт, вс 10:00–22:00; пт, сб 10:00–23:00", "source": "https://..."},
        "phone":    {"verdict": "wrong", "value": "+7 (495) 790-70-90 доб. 219", "source": "https://..."},
        "url":      {"verdict": "ok",    "value": "https://osteriamario.ru/", "source": "https://osteriamario.ru/"},
        "price":    {"verdict": "unknown", "value": null, "source": null},
        "how":      {"verdict": "ok",    "value": "Вход: через ТЦ «Европейский»\nЭтаж: 3, атриум «Париж»", "source": "https://..."},
        "age":      {"verdict": "ok",    "value": [0, 14], "source": "https://..."},
        "kidsroom": {"verdict": "ok",    "value": "есть, 12:00–20:00", "source": "https://..."}
      },
      "note": "коротко, что важно"
    }
  ]
}
```
- **Важно: всё, что ты пишешь со ссылкой-источником, применяется в приложении АВТОМАТИЧЕСКИ, без проверки человеком**
  (Вадим 10.11). Поэтому ставь `wrong`/`ok` только когда видишь это на странице сам. Сомневаешься — `unknown`.
- `status: "closed"` — только если источник прямо говорит «закрыто / больше не работает / нет в списке филиалов»;
  ссылку дай в поле `"sources": ["https://…"]` у места (и/или в полях). Без ссылки закрытие не применяется.
- Форматы значений (иначе поле не применится и уйдёт на ручной разбор):
  `hours` — «пн-пт 10:00-22:00; сб-вс 11:00-23:00» или «ежедневно 10:00-22:00» (24-часовой формат);
  `point` — `[lat, lon]` входа в само заведение по карточке организации, + `distance_m`; дальше 500 м от нашей точки
  не применяется автоматически; `price` у кафе — число (средний чек на взрослого, ₽); `age` — `[от, до]`;
  `how` — строки «Вход: …», «Этаж: …», «Домофон: …», «Шлагбаум: …», «Парковка: …», «Ориентир: …» через \n,
  только подтверждённое (без «не подтверждено», «уточняйте»).
- `verdict`: **ok** — наше значение совпало с источником; **wrong** — в источнике другое (в `value` — правильное);
  **unknown** — не удалось проверить (не выдумывать!).
- Для каждого `ok`/`wrong` обязательна ссылка `source` на страницу, где это видно. Без ссылки — `unknown`.
- Только JSON, без пояснений вокруг.

## Автоматический режим (по расписанию)
Основной способ — Codex по подписке ChatGPT (gpt/CODEX-SETUP.md): робот gpt-codex.yml каждый час держит в работе
несколько пачек (pull request с gpt/slices/<имя>.json и комментарием @codex), задача описана в AGENTS.md. Ещё вариант —
задача по расписанию на сайте ChatGPT (в облаке): gpt/CHATGPT-TASK.md. Запасной — приложение
Codex на компьютере: gpt/CODEX.md. Отчёт — файл в gpt/reports/ (ветка main или pull request) или issue
«Отчёт ChatGPT …» с JSON: всё принимается и применяется автоматически.

## Куда класть отчёт
Если у тебя есть доступ к GitHub (Codex / подключённый репозиторий) — создай файл в `gpt/reports/` репозитория
`vadimsurov-apps/kudapoiti-data` (коммит в main или pull request). Если доступа нет — выдай JSON целиком в ответе,
Вадим перешлёт его.

Что будет дальше: наш робот сверит отчёт. Совпадения засчитываются как вторая независимая проверка; расхождения
(`wrong`) мы перепроверяем по твоему источнику и исправляем, если подтвердилось.
